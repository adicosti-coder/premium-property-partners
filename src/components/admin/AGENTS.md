# Admin components rules
- WhatsApp admin work lives in the single `hub-whatsapp` screen (`WhatsappHub.tsx`): queue/attention/report rules come only from `supabase/functions/_shared/waHubRules.ts` (tested in `src/lib/waHub.test.ts`), quick actions (retry/unblock, test send, resolve) go only through the admin-only `wa-hub-actions` function, which logs each one in `admin_audit_log`; legacy WhatsApp pages stay reachable as hub tools and old URLs — keeps one classification of 131042/131026/duplicates and no secret or test number in the browser.
- Collected-listing triage (`triere-anunturi`, `ScrapedListingsTriage.tsx`) groups cross-portal duplicates only via `src/lib/crossPortalDedup.ts` (cross-portal only, every variant must match the group's primary, implausible prices/sizes ignored) and filters/orders via `src/lib/scrapedListingsTriage.ts`, both tested; sending goes through `andrei-bulk-queue` and is blocked client-side by `triageBlockReason` when no phone was extracted — avoids merging distinct homes and queuing listings that need a manual phone reveal.
- Triage „Indisponibil / Renunță” goes only through admin RPCs `admin_dismiss_prospect` / `admin_restore_prospect`: the listing becomes inactive + `expired`, leaves the first-message queue, its pending WhatsApp/owner-outreach/call items are cancelled, the previous state is kept in `dismissed_prev` for undo and both actions are audited; the list hides dismissed listings before duplicate grouping via `triagePool` — nothing is deleted, and a dismissed primary never hides its live variants.
- Triage „Confirmă privat” goes only through admin RPCs `admin_confirm_prospect_private` / `admin_undo_confirm_prospect_private` (audited, previous state in `private_confirm_prev`); `private_confirmed_at` makes `classify_seller_type` keep `privat` (agency blocklist still wins), agency-flagged rows need the separate override dialog and text-keyword agencies are refused; the button choice comes from `privateConfirmMode` — confirmation survives reclassification and undo restores the exact prior classification.
