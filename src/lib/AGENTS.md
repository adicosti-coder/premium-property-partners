# Lib rules
- Company facts (start years, contact hours, guest score and review count) live only in `businessFacts.ts`, alias-free so prerender and scripts import it; edge functions use the parity-tested mirror `_shared/guestReputation.ts` — pages never hardcode these, preventing contradictory claims.
- Shortcut destinations on the admin „Astăzi” screen come from `adminTodayRoutes.ts` (tested), and `WhatsappChat` opens the conversation given by `?phone=` — keeps cards and lists pointing at the step or filter that resolves them.
- Review/AggregateRating JSON-LD is built only by `reviewStructuredData.ts` (1–10 on-page scale, invalid reviews dropped) on a single LodgingBusiness node; property pages emit it through the effect-managed `JsonLdScript`, and the homepage brand rating comes only from `GUEST_REPUTATION` in `businessFacts.ts`, shared with the visible badge — prevents conflicting scales, stale duplicate rating nodes and markup that differs from the page.
