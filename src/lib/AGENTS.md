# Lib rules
- Company facts (start years, contact hours, guest score and review count) live only in `businessFacts.ts`, alias-free so prerender and scripts import it; edge functions use the parity-tested mirror `_shared/guestReputation.ts` — pages never hardcode these, preventing contradictory claims.
- Shortcut destinations on the admin „Astăzi” screen come from `adminTodayRoutes.ts` (tested), and `WhatsappChat` opens the conversation given by `?phone=` — keeps cards and lists pointing at the step or filter that resolves them.
- Review/AggregateRating JSON-LD is built only by `reviewStructuredData.ts` (1–10 on-page scale, invalid reviews dropped) on a single LodgingBusiness node; property pages emit it through the effect-managed `JsonLdScript`, and the homepage brand rating comes only from `GUEST_REPUTATION` in `businessFacts.ts`, shared with the visible badge — prevents conflicting scales, stale duplicate rating nodes and markup that differs from the page.
- Legacy route redirects in `App.tsx` use `RedirectWithQuery` (`redirectWithQuery.ts`, tested), never a bare `<Navigate>` — keeps `?lang=en`, campaign parameters and hash on the new address.
- Static pages count as fully translated only when listed in `TRANSLATED_STATIC_PATHS` (`seoLanguagePolicy.ts`, parity-tested mirror in `_shared/seoLanguage.ts`); that list alone drives their `?lang=en` canonical, hreflang, prerender head and sitemap entry — keeps page, prerender and sitemap in agreement.
- Calculator sale value uses one €/mp chain: `get_calculator_sale_benchmark` RPC (aggregate-only medians of collected listings, then `timisoara_market_indices`) with `gridSaleBenchmark` as last fallback, also used by /evaluare-gratuita; refinement percentages live only in `calculatorRefinements.ts` — keeps sale, nightly and occupancy adjustments identical across screens, PDF and leads.
- Property name trimming, the nightly-price ceiling and the minimum sale price live in `propertyDataRules.ts` (tested) for admin forms and are mirrored by DB trigger `trg_normalize_property_fields`, which silently corrects imports (moves misplaced sale/rent prices to `capital_necesar`, nulls sub-threshold sale prices) — keep both constants in sync so imports never fail while forms block typos.
